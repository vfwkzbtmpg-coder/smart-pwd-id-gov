Authentication Required

All API endpoints require an API key in the X-API-Key header. Contact your administrator to obtain an API key.

Health Check

GET /api/public/health

Check API health status. No authentication required.

Response 200 OK

{ "status": "healthy", "service": "Smart PWD ID Public API", "version": "1.0.0", "timestamp": "2024-01-15T10:30:00.000Z", "documentation": "/api-docs" }

Verify PWD ID

GET /api/public/verify/:pwdId

Verify a single PWD ID. Use for QR code or NFC tap verification.

Parameter Type Required Description
pwdId string Required The PWD ID to verify (e.g., "pwd-1")
method string Optional Verification method: "QR", "NFC", or "manual"

Success Response 200 OK

{ "status": "verified", "message": "PWD ID is valid", "data": { "id": "pwd-1", "firstName": "Ken Mijay", "lastName": "Espiritu", "validUntil": "Aug 12, 2031" }, "verifiedAt": "2024-01-15T10:30:00.000Z", "verificationMethod": "QR" }

Error Response 404 Not Found

{ "status": "not_found", "message": "PWD ID not found or invalid", "verifiedAt": "2024-01-15T10:30:00.000Z" }
POST /api/public/verify

Batch verify multiple PWD IDs (max 100 per request).

Parameter Type Required Description
pwdIds array Required Array of PWD IDs to verify
method string Optional Verification method
// Example Request Body { "pwdIds": ["pwd-1", "pwd-2", "pwd-3"], "method": "QR" }

Check PWD ID Status

GET /api/public/status/:pwdId

Check the status of a PWD ID (active, expired, suspended, flagged).

Parameter Type Required Description
pwdId string Required The PWD ID to check

Response 200 OK

{ "status": "success", "data": { "id": "pwd-1", "status": "active", "firstName": "Ken Mijay", "lastName": "Espiritu", "registeredAt": "2024-01-15T10:30:00.000Z", "validUntil": "Aug 12, 2031", "flags": [] }, "checkedAt": "2024-01-15T10:30:00.000Z" }

Establishments

GET /api/public/establishments

List all establishments that accept Smart PWD ID verification.

Response 200 OK

{ "status": "success", "total": 1, "data": [ { "id": "est-1", "name": "Sample Verifier", "email": "verifier@smartpwd.ph" } ] }

Public Statistics

GET /api/public/stats

Get public statistics about the Smart PWD ID system.

Response 200 OK

{ "status": "success", "data": { "totalPwds": 1, "totalEstablishments": 1, "totalVerifications": 5, "successfulVerifications": 3, "successRate": "60.00%" }, "lastUpdated": "2024-01-15T10:30:00.000Z" }

Recent Transactions

GET /api/public/transactions/recent

Get recent verification transactions.

Parameter Type Required Description
limit integer Optional Number of transactions to return (default: 10, max: 100)

Rate Limits

API requests are rate-limited per API key. The default limit is 100 requests per hour.

Error Response 429 Too Many Requests

{ "error": "Rate limit exceeded", "message": "You have exceeded the rate limit of 100 requests per hour", "retryAfter": "1 hour" }
